Requires a browser with the Web Bluetooth API (e.g. Bluefy on iOS, or Chrome/Edge on desktop/Android) served from a secure context (https://, or a local file the browser trusts). Turn on Config → Advanced → Toggle BLE API on the Bruce before connecting. Commands follow the Bruce serial reference — the on-screen navigation keys aren't part of that public spec, so treat the Remote control card as a starting point to adjust for your firmware.
